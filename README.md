# Blog Market Application

Веб-приложение "Витрина интернет-магазина" на Spring Boot.  
Пользователи могут просматривать товары, добавлять их в корзину, оформлять заказы и просматривать историю покупок.
## Технологии

- **Java 21** — основной язык
- **Spring Boot 3.2** — автоконфигурация, встроенный Netty
- **Spring WebFlux + Thymeleaf** — реактивные контроллеры и шаблоны страниц
- **Project Reactor** (Mono/Flux) — реактивная обработка данных
- **Spring Data R2DBC** — реактивная работа с БД
- **PostgreSQL** — основная БД (через R2DBC-драйвер)
- **H2 (R2DBC)** — тесты
- **Lombok** — сокращение кода
- **JUnit 5 + Mockito + Reactor Test** — тестирование
- **Gradle** — сборка

## Функциональность

- **Главная страница** — витрина товаров с пагинацией, поиском и сортировкой
- **Страница товара** — детальное описание, добавление в корзину
- **Корзина** — список товаров, изменение количества, удаление, итоговая сумма
- **Заказы** — история заказов, детали каждого заказа
- **Оформление заказа** — создание заказа из корзины

## Требования

- Java 21 (JDK 21 или выше)
- PostgreSQL 15.x или выше (с поддержкой R2DBC)
- Gradle 8.x

## Сборка
```bash
./gradlew clean build
```

## Запуск тестов
```bash
./gradlew test
```

## Запуск
```bash
java -jar build/libs/my-market-app.jar
```
